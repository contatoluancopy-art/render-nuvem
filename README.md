# render-nuvem

Render dos vídeos do canal em máquinas do GitHub Actions, um bloco por máquina, até 20 ao mesmo tempo.
Quem dispara é o `canal-biblico/_esteira/render_nuvem.py` do PC do Luan. Aqui ficam só a esteira e os arquivos visuais
de cada vídeo (páginas, cenas, imagens e fonte), sem narração nem música: o áudio entra no PC, na hora de juntar.
